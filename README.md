# 🔮 Artificial Intelligence in Interactive Systems (SS25)

[](https://github.com/Pleanog/lmu-course-naco#-natural-computing-ss25)

This repository contains mostly lecture material, some definitions, and exercises and **study notes** for the course **Artificial Intelligence in Interactive Systems (SS25)**.
Formerly knows as *Practical Machine Learning*.

---

## Repository Structure

1. **Exercises**: Notes taked during the exercises or some solutions to the given exercises.
2. **Lectures**: Lecture-specific notes (e.g., summaries and detailed explanations from individual sessions).
3. **Lecture Slides**: Contains Lecture Slides as given by the Prof.

---

## Tools and Notes

- **Obsidian**:
    - Used exclusively for note-taking and organizing course content.
    - No plugins or customizations are required.
    - All notes are stored in markdown format.
- **File Naming Convention**:
    - e.g., `Definition 19 (Nash equilibrium).md`
    - or `Algorithm 4 (basic evolutionary algorithm).md`.
- **Content Format**:
    - Diagrams and images are included in  `AII/Images/`.
